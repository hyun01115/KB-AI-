# KB 소상공인 창업 입지 추천 서비스

> **KB AI 해커톤 2026** — 소상공인이 창업 전에 최적 입지를 찾고 KB 금융서비스와 연결되는 AI 추천 서비스

## 서비스 개요

업종·지역·예산·우선순위를 입력하면:
1. **후보 입지 3곳** 추천 + 지도 표시
2. **3년 영업 지속 가능성 추정치** (Cox 생존분석 모델)
3. **추천 근거 카드** (유동인구, 경쟁 점포, 임대료 추이)
4. **유사 사례 통계** (과거 동일 조건 점포 생존율)
5. **총 필요자금 · 추가 조달 필요금액 · KB 금융상품 매칭**
6. **예상 금융부담 신호등** (월매출 대비 부담 비율)
7. **스트레스 테스트** (금리+1%p / 임대료+10% / 매출-30%)
8. **균형형·성장형·안정형 목적별 최종 추천**

## 데이터 출처

| 데이터 | 출처 | 활용 목적 |
|--------|------|-----------|
| 개업·폐업 이력 | 공공데이터포털 지방행정인허가 | 생존분석 모델 학습 |

## 빠른 시작

```bash
# 1. 의존성 설치
pip install -r requirements.txt

# 2. 환경변수 설정
cp .env.example .env
# .env 파일에 API 키 입력 (시연은 DEMO_MODE=true 로 가능)

# 3. Streamlit 앱 실행
streamlit run app.py

# 또는 FastAPI 백엔드 실행
uvicorn api:app --reload
```

## 모델 구성

### Cox 비례위험모델 (화면·설명용)
```
S(t) = S0(t)^exp(βX)
```
| 변수 | 해저드비 | 해석 |
|------|---------|------|
| 반경 300m 경쟁 점포 수 | 1.049 | 1개 증가 시 폐업위험 4.9% 상승 |
| 3년 임대료 상승률 | 1.032 | 1%p 상승 시 폐업위험 3.2% 상승 |
| 유동인구 구 평균 대비 비율 | 0.978 | 비율 높을수록 폐업위험 감소 |

### XGBoost 생존모델 (오프라인 검증용)
- 비선형 관계 및 변수 상호작용 추가 확인
- Cox 모델과 성능 비교 후 최종 채택

## 종합 추천점수 산식

```
종합 추천점수 = 0.35 × 안정성 + 0.30 × 수익성 + 0.20 × 금융실행가능성 + 0.15 × 선호적합성
```
(각 지표는 0~100으로 정규화 후 가중합)
